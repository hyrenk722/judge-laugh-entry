Entry for the make.fun competition "Make the AI Judge Laugh": one joke about
office life, a single line under 200 characters. `main.py` writes that joke
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validating the
gate first: UTF-8 text, 1–200 characters, not only whitespace, exactly one
line — then reading the file back to verify the written bytes match.

> Our boss calls it an open-plan office, but the only thing open is the tab with the job listings.

Why this joke: it is true to the office twice over — the open-plan office and
the job-listings tab are both things every office worker recognises — and the
turn pivots on a single word, "open": the boss's "open-plan" promise collapses
into the one thing that is actually open, a browser tab for leaving. One line,
no wasted setup, reads cleanly aloud in one breath, and the last word lands
the laugh instead of explaining it.
